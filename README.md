# Vehicle Price Prediction - Go Auto Project

This project focuses on building a machine learning model to predict optimal vehicle prices based on features such as make, model, year, and mileage. The goal is to help dealerships fine-tune pricing strategies to stay competitive and maximize sales.

## Project Overview
- **Problem Statement:** Predict vehicle prices using available car features.
- **Approach:** Data cleaning, feature engineering, and regression modeling.
- **Outcome:** Developed and evaluated multiple models to forecast prices accurately.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Key Steps
1. Data Preparation and Cleaning (handling missing values, outliers, encoding)
2. Exploratory Data Analysis (EDA) to understand key pricing drivers
3. Model Building (Linear Regression, Random Forest Regressor, Gradient Boosting)
4. Model Evaluation (R² Score, RMSE)
5. Deployment using a basic Streamlit app (optional for future work)

## Project Files
- `Go_Auto_Original_Updated.ipynb`: Main Python notebook containing all the code, analysis, and models.

## Future Enhancements
- Hyperparameter tuning for improved accuracy
- Integration into a full web app for real-time price predictions
